# Dataset

`ai4i2020.csv` is the **AI4I 2020 Predictive Maintenance Dataset** from the
UCI Machine Learning Repository.

- DOI: https://doi.org/10.24432/C5HS5C
- Dataset page: https://archive.ics.uci.edu/dataset/601/ai4i+2020+predictive+maintenance+dataset
- License: Creative Commons Attribution 4.0 International (CC BY 4.0)
- Citation: AI4I 2020 Predictive Maintenance Dataset [Dataset]. (2020). UCI
  Machine Learning Repository.

The dataset is synthetic, contains 10,000 records, and is designed to reflect
real industrial predictive-maintenance measurements. It contains no missing
values. The five failure-mode labels (`TWF`, `HDF`, `PWF`, `OSF`, `RNF`) are
retained for auditability but are never passed to the model because that would
leak target information.
